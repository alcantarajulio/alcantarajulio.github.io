This guide follows the 522CIT module, which runs on the Cisco Networking Academy
Network Security track. It is the longest of the three.

**Before you start.** Every chapter has two parts: the theory, which you can read
anywhere, and a practical section at the end with annotated Cisco IOS configuration. To
follow the practical part you need **Cisco Packet Tracer**, which Cisco distributes at no
cost to anyone enrolled in the Networking Academy. Chapters 6 and 8 also need a Linux
machine with OpenSSL and Nmap, because the simulator implements neither cryptography nor
scanning. The guide does not reproduce the
course lab files, which remain licensed Cisco material and cannot be redistributed here,
and it points at the end of each chapter to the labs that match the subject.

Eight chapters: device access control, hardening and monitoring, AAA, traffic filtering,
intrusion prevention and endpoint defence, layer 2 attacks, applied cryptography,
site-to-site VPNs, and security testing.
